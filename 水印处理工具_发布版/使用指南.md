# 水印处理工具使用指南

## 🚀 快速开始

### 第一步：导入图片
1. 点击左侧面板的 **"选择图片"** 按钮，选择单张或多张图片
2. 或者点击 **"选择文件夹"** 按钮，导入整个文件夹的图片
3. 导入的图片会显示在下方的列表中

### 第二步：设置水印
在右侧面板选择水印类型：

#### 文本水印
1. 切换到 **"文本水印"** 选项卡
2. 输入水印文字（支持中文）
3. 选择字体（推荐使用"微软雅黑"以支持中文）
4. 调整字体大小、颜色、透明度
5. 可选择添加阴影或描边效果

#### 图片水印
1. 切换到 **"图片水印"** 选项卡
2. 点击"选择"按钮，选择水印图片（建议使用PNG格式）
3. 调整缩放比例和透明度

### 第三步：调整位置
1. 切换到 **"位置样式"** 选项卡
2. 使用九宫格按钮快速定位水印位置
3. 或者直接在预览区域拖拽水印到想要的位置
4. 可以调整旋转角度

### 第四步：配置导出
在左侧面板的"导出设置"区域：
1. 选择输出格式（PNG或JPEG）
2. 如果选择JPEG，调整图片质量
3. **重要**：选择输出文件夹（不能与原图片文件夹相同）
4. 选择文件命名规则

### 第五步：开始处理
1. 确认所有设置无误
2. 点击左侧面板底部的 **"🚀 开始批量导出"** 按钮
3. 等待处理完成

## 💡 使用技巧

### 实时预览
- 所有设置更改都会立即在预览区域显示
- 点击图片列表中的不同图片可以预览效果

### 模板功能
1. 切换到 **"模板管理"** 选项卡
2. 输入模板名称，点击"保存"保存当前设置
3. 下次使用时可以直接加载模板

### 中文字体支持
- 默认使用"微软雅黑"字体
- 如果显示方框，请选择其他中文字体：宋体、黑体、楷体、仿宋

### 拖拽定位
- 在预览区域直接用鼠标拖拽水印到精确位置
- 比九宫格定位更灵活

## ⚠️ 注意事项

1. **输出文件夹**：必须选择与原图片不同的文件夹，避免覆盖原文件
2. **中文字体**：如果中文显示为方框，请更换字体
3. **图片格式**：PNG格式保持最佳质量，JPEG格式文件更小
4. **批量处理**：处理大量图片时请耐心等待
5. **水印图片**：建议使用PNG格式的透明背景图片作为水印

## 🔧 故障排除

### 中文显示方框
- 更换字体为"微软雅黑"、"宋体"或"黑体"
- 确保系统已安装中文字体

### 无法导出
- 检查是否选择了输出文件夹
- 确保输出文件夹有写入权限
- 检查磁盘空间是否充足

### 预览不显示
- 检查图片格式是否支持
- 尝试重新导入图片
- 重启应用程序

## 📞 技术支持

如果遇到其他问题，请检查：
1. Python版本是否为3.7+
2. 是否正确安装了Pillow库
3. 图片文件是否损坏
4. 系统字体是否完整
